## 📖 專案概述

本專案為花蓮夢N研習「**點亮備課、運課與回饋的Agent技能樹**」專題之**全方位數位典藏平台**。
不同於僅保留超連結的傳統導覽，本站達成**「網頁版面完整鏡像複製」**與**「所有實作教材與技能檔案實體離線典藏」**。

本站支援多種瀏覽模式（看板瀑布流視角、網格總覽視角、19項本機檔案清單），並為教師學員提供一鍵複製提示詞、各項教材即時預覽與本機下載功能。

## 🛠️ 系統特色與功能

- **安全通行機制**：採用瀏覽器原生 SHA-256 加密雜湊驗證，保護研習內部專屬教材資源。
- **三種視角無縫切換**：
  - **看板視角 (Shelf Board)**：高度還原 Padlet 原站的 15 欄橫向滑動瀑布流佈局。
  - **網格視角 (Grid View)**：自適應多欄網格，適合大螢幕快速瀏覽與搜尋。
  - **檔案典藏庫 (Files Archive)**：一覽所有本機檔案並提供一鍵直接下載。
- **卡片功能強化**：
  - 提示詞區塊採等寬字型排版，支援一鍵複製到剪貼簿。
  - 圖片支援 Lightbox 燈箱放大檢視。
  - Markdown 檔案支援免跳頁直接線上渲染預覽。
  - 快速搜尋列支援主題、內文、提示詞、分欄與附件名稱即時比對。
  - 內建 QR Code 分享功能，便於學員使用手機或平板快速掃碼開啟。
